# K.K International corporate website starter

A responsive static multi-page corporate website designed for GitHub Pages.

## Pages
- `index.html` — Home
- `about.html` — Company profile
- `divisions.html` — Business divisions
- `products.html` — Product categories and enquiries
- `trade.html` — Import/export process
- `contact.html` — Contact placeholder

## Before publishing
1. Confirm and register the final domain name.
2. Replace the temporary email link in `contact.html` with the official business email.
3. Add the confirmed phone/WhatsApp number, full business address, and any approved logo.
4. Review all company descriptions and product statements for accuracy.
5. Add a root-level `CNAME` file containing the chosen domain after registration and configure GitHub Pages DNS.

No claims of licences, certifications, years of experience, exclusive distributorships, or current product stock have been invented. Product categories are presented as areas of business interest, not a promise of availability or regulatory approval.

## Deploy
Publish the repository root with GitHub Pages (Deploy from a branch, `main` / root). For a custom domain, add it under repository Settings → Pages and follow GitHub's current DNS instructions: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site
